# Hello Kitty Fan Page

Página web dedicada a Hello Kitty, diseñada para compartir información, imágenes y detalles de su universo kawaii.

## Descripción

Hello Kitty Fan Page es un sitio web creado como homenaje a uno de los personajes más reconocidos de Sanrio. Cuenta con un diseño visual en tonos rosas, una presentación de bienvenida, información sobre el personaje y una galería de imágenes.

## Funcionalidades

- Página principal de bienvenida.
- Sección informativa sobre Hello Kitty.
- Galería de imágenes.
- Navegación entre secciones mediante menú.
- Diseño visual con temática kawaii.
- Efectos visuales e interacciones al pasar el cursor.
- Diseño adaptable a dispositivos móviles.
- Sección de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3

## Instalación local

1. Clona este repositorio:

```bash
git clone https://github.com/7Marilu7/FanPage.git
```

2. Accede a la carpeta del proyecto:

```bash
cd FanPage
```

3. Abre el archivo `index.html` directamente en tu navegador.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para visualizar el proyecto en un servidor local.
